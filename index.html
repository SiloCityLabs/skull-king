Scoring

Classic

  • Exact non-zero bid: +20 per trick won
  • Exact zero bid: +10 × cards dealt
  • Missed bid: −10 × |bid − won|
  • Bonuses count only when the bid is exact

Bonuses (enter raw totals)

  • Color 14s: +10 each · Black 14: +20
  • Pirate captures Mermaid: +20
  • Skull King captures Pirate: +30 each
  • Mermaid captures Skull King: +40
  • Loot alliance (both bids exact): +20 each

Rascal’s scoring

  • Grapeshot: 10 × cards if exact; half if off by 1; else 0 (bonuses scale the same)
  • Cannonball: 15 × cards if exact; else 0 (including bonuses)
